# متابعة مهام المدير التنفيذي — جمعية تنمية تندحة الأهلية (4485)

موقع داخلي لمتابعة مهام المدير التنفيذي:

- ➕ إضافة مهمة يدوياً أو استيراد من ملف Excel/CSV
- 📅 تاريخ التنفيذ عبر التقويم + ⏳ عدّاد المتبقي من تاريخ اليوم
- 🚩 الأولوية: مهم جداً / مهم / متوسط الأهمية / غير مهم
- 👤 مسؤول التنفيذ + 📎 شواهد التنفيذ (PDF/PNG/JPG)
- 📊 تقارير وتصدير XLS و PDF
- 🎨 الهوية مستوحاة من شعار الجمعية — `logo.JPG`

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو انشره عبر GitHub Pages.

## الاستيراد

استخدم زر «نموذج الاستيراد» لتنزيل قالب Excel بالأعمدة:
`المهمة | الوصف | تاريخ التنفيذ | الأولوية | المسؤول`
